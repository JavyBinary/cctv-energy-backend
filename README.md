# Веб-сервис расчета энергопотребления системы видеонаблюдения

Проект разрабатывается в рамках курса «Разработка Интернет Приложений» (МГТУ им. Н.Э. Баумана).
Студент группы ИУ5-51Б Чоботов Лука Константинович

## Предметная область
Система предназначена для расчета параметров электропитания и эксплуатационных затрат комплексов охранного телевидения:
- **Услуги (Компоненты)**: Модели камер видеонаблюдения (тип исполнения, мощность, размещение).
- **Заявка**: Расчет суммарного суточного энергопотребления (кВт·ч) и месячной стоимости электроэнергии.

## Технологический стек
- **Backend**: Python 3.10+, FastAPI, Uvicorn, Jinja2
- **Data & Storage**: SQLAlchemy, Alembic, MinIO (S3 Object Storage в Docker)
- **UI Architecture**: Портретный режим (мобильная верстка), Server-Side Rendering (SSR)
